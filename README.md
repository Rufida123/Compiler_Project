# Compiler_Project
This is a university project about making a compiler for a Flask and Jinja2 project

## Persistent products and manual rendering

The Flask application reads its product list from `data/products.json`.
Submitting the Add Product form updates that JSON file immediately. Static HTML
in `output/` is intentionally not regenerated by Flask.

After adding or changing a product, run the compiler again from the project root
to synchronize the generated HTML with the saved data:

```powershell
java -cp ".build\classes;dependencies\antlr-4.13.2-complete.jar" app.Main
```

Then open `output/index.html` in a browser. Compiler diagnostics and generation
metadata are written to `compiler_output/`.

Typical workflow:

1. Start Flask with `py -3.12 app.py`.
2. Add a product at `http://127.0.0.1:5000/add`.
3. Stop Flask if desired; the product remains saved in `data/products.json`.
4. Run the Java compiler command above.
5. Refresh `output/index.html` to see the newly generated product.

The generator also copies `style.css` and `script.js`, when present beside
`app.py` or inside `templates/`, without parsing or modifying them.
